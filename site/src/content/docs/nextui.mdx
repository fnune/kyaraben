title: NextUI integration

Kyaraben can synchronize saves and ROMs with handheld devices that run MinUI or NextUI. For example, start a game on your PC and continue it on the handheld.

## Supported devices

The NextUI integration works with devices that run MinUI or NextUI firmware. Only the TrimUI Brick is tested. The other devices can work, but nobody has tested them.

- TrimUI Brick (tested)
- TrimUI Smart Pro
- Anbernic RG35XX H, Plus, SP, 2024
- Miyoo Mini, Mini+
- RGB30

## Installation

1. Download `Kyaraben.pak` from the [GitHub releases page](https://github.com/fnune/kyaraben/releases).
2. Connect the SD card of your device to your computer.
3. Extract `Kyaraben.pak` to the `Tools/` directory on the SD card. For the TrimUI Brick, this is `Tools/tg5040/Kyaraben.pak/`.
4. Eject the SD card and put it back into your device.

The Kyaraben app appears in the Tools menu on your device.

## Configuration

The default configuration maps Kyaraben system IDs to the standard NextUI paths. If you use other paths or other cores, create a config file at `/.userdata/<platform>/kyaraben/config.toml` on the SD card. For the TrimUI Brick, this is `/.userdata/tg5040/kyaraben/config.toml`.

Example:

```toml
[service]
autostart = true
ignore_delete_roms = false

[saves]
nes = "Saves/FC"
snes = "Saves/SFC"
gb = "Saves/GB"
gbc = "Saves/GBC"
gba = "Saves/GBA"
psx = "Saves/PS"

[roms]
nes = "Roms/Nintendo (FC)"
snes = "Roms/Super Nintendo (SFC)"
gba = "Roms/Game Boy Advance (GBA)"
psx = "Roms/PlayStation (PS)"

[bios]
gba = "Bios/GBA"
psx = "Bios/PS"

[screenshots]
retroarch = "Screenshots"
```

The left side of each mapping is a Kyaraben system ID, the same as the folder names in your desktop collection. The right side is the path on the device, relative to the SD card root.

## Using the app

Launch Kyaraben from the Tools menu on your device. The main screen shows:

- Status: shows if sync runs and is connected
- Syncing: turns synchronization on or off
- Autostart: starts sync when the device boots
- Sync states: synchronizes save states (off by default)
- Keep deleted ROMs: keeps the ROMs on this device when another device deletes them (off by default)
- Pair new device: generates or accepts a pairing code
- View paired devices: shows the connected devices

### Pairing

To pair with your desktop:

1. On your desktop, run `kyaraben sync pair`, or use the UI to generate a pairing code.
2. On your device, select "Pair new device" > "Enter pairing code".
3. Enter the 6-character code.

You can also generate the code on the device and enter it on your desktop.

### Sync states

Save states do not sync by default. States are often not compatible between emulator versions or platforms, and RetroArch on your desktop can use different cores than NextUI. Enable this setting only if your devices use compatible cores.

### Ignore ROM deletions

With `ignore_delete_roms = true`, a ROM deletion on another device does not remove the ROM from this device. Kyaraben devices have the same protection. On the handheld it is off by default, because handheld cards fill quickly and deletions free space.

Turn it on if the handheld must keep all its ROMs. The setting protects only this device. A rename on another device arrives as a delete and a create, so the file with the old name can stay as a duplicate.

## What syncs

See the [collection reference](/collection/#what-syncs) for the full list. Differences for NextUI devices:

- Save states do not sync by default, because desktop and handheld cores can be incompatible.
- EmulationStation DE metadata and media do not sync, because NextUI uses its own format.
- Saves and states keep 30 days of [file versions](/collection/#file-versioning) on the card, the same as Kyaraben devices. You can undo a deletion.
- [ROM deletion protection](/collection/#protecting-roms-from-deletion) is off by default, the opposite of Kyaraben devices. To keep the ROMs on this device, set `ignore_delete_roms = true` under `[service]`. Always keep protection on for the device that holds your full library.
