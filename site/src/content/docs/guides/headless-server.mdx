---
title: Headless server
description: Set up a sync-only hub on a headless Linux server
---

Run Kyaraben on a headless Linux server as a central sync hub. The server stores your collection and syncs it with the devices that run emulators. For example:

- Home server as the primary storage for ROMs and saves
- NAS device syncing to multiple gaming machines
- Cloud VPS as a backup destination

## Requirements

- x86_64 Linux (no GUI needed)
- systemd user services support
- Sync ports accessible (see [Syncthing's firewall documentation](https://docs.syncthing.net/users/firewall.html))

:::note[Port numbers]
Kyaraben uses different ports than default Syncthing:

- TCP 22100 (sync traffic, default is 22000)
- UDP 21127 (local discovery, default is 21027)

If you have firewall rules for Syncthing, update them to these ports.
:::

## Installation

Download the CLI binary from [GitHub releases](https://github.com/fnune/kyaraben/releases):

```bash
curl -fsSL https://github.com/fnune/kyaraben/releases/latest/download/kyaraben-cli-linux-amd64 -o kyaraben
chmod +x kyaraben
sudo mv kyaraben /usr/local/bin/
```

## Setup

Initialize a headless configuration:

```bash
kyaraben init --headless --collection /path/to/emulation
```

This creates `~/.config/kyaraben/config.toml` with:

```toml
[global]
collection = "/path/to/emulation"
headless = true

[sync]
enabled = true
```

Apply the configuration:

```bash
kyaraben apply
```

This creates the directory structure for all systems and installs Syncthing. It installs no emulators.

## Persistence

To keep Syncthing running after you disconnect from SSH, let user services run without a login session:

```bash
loginctl enable-linger $USER
```

## Pairing devices

Generate a pairing code on the server:

```bash
kyaraben sync pair
```

On your desktop or Steam Deck, enable synchronization and enter the code.

The pairing code needs access to the Syncthing relay. If the code does not work, use the device ID:

```bash
kyaraben sync pair --device-id
# Copy the full ID and enter it on the other device
```

## Managing files

Place ROMs directly in the collection:

```bash
cp game.chd /path/to/emulation/roms/psx/
```

The directory structure follows [Kyaraben's collection layout](/collection/). Files sync automatically to paired devices.

## Monitoring

Check sync status:

```bash
kyaraben sync status
```

This shows if sync runs, the connection status, the paired devices, the synced folders, and connectivity warnings.

If sync shows "not running", check the Syncthing service:

```bash
systemctl --user status kyaraben-syncthing
```

For more detail, open the Syncthing web UI at `http://server-ip:8484`.

## Updating

Keep the CLI up to date:

```bash
kyaraben update
```

## Remote syncing

By default, Kyaraben syncs only devices on the same local network. To sync across networks, for example with a cloud VPS or a remote home server, enable global discovery. Global discovery announces your device to the Syncthing discovery servers, so that devices can find each other on the internet.

Add this to your config:

```toml
[sync.syncthing]
global_discovery_enabled = true
relay_enabled = true
```

Global discovery lets devices find each other. Relays transfer data when a direct connection is not possible.

:::caution[Untested]
Nobody has tested remote syncing with global discovery end-to-end. If you find problems, [report them](https://github.com/fnune/kyaraben/issues).
:::

## Troubleshooting

### Service not starting after reboot

Verify linger is enabled:

```bash
loginctl show-user $USER | grep Linger
```

Check service status:

```bash
systemctl --user status kyaraben-syncthing
```
